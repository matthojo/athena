Save to Athena

Keep pages, quotes, images and links in your Athena.

The address you open Athena at.

In Athena, go to Settings → API keys and make a capture key. It can add things to Athena but can't read anything back.

    How to save

    • Toolbar button saves the page you're on. Add a note in the window that opens.
    • Right-click a page, a selection, an image or a link and pick Save. A selection is kept word for word as a quote, with the page it came from.
    • Alt+Shift+S saves the page without opening anything. You can change it in the browser's extension shortcuts.

    If Athena can't be reached, saves wait here and go when it's back. Nothing is dropped without you removing it.

    Privacy

    The extension sends saves only to the address above, and nowhere else. There are no analytics. The key stays in this browser's extension storage, and the browser asks you before the extension can reach your Athena.
