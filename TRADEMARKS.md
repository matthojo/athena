# The Athena name and logo

The code is yours to use under the [AGPL](LICENSE). The Athena name and logo
are not covered by that licence: they tell people that something is the
project's own release, and this policy keeps them meaning that.

## Fine without asking

- Running your own copy of Athena, changed or not, and calling it Athena.
- Saying that your project is "based on Athena", "a fork of Athena" or
  "works with Athena", as long as it's clear it isn't the project's own.
- Writing, teaching or making videos about Athena, using the name and the
  unaltered logo to refer to it.
- Linking to this repository with the logo.

## Ask first

- Offering Athena, or anything built from it, as a hosted service for
  other people, paid or free, under the Athena name or logo, or a name that
  could be mistaken for it.
- Selling anything (an app, a plugin, merchandise) that uses the name or
  logo.
- Using a changed version of the logo, or putting the name or logo in your
  own product's name, domain or app icon.

## If you fork

A public fork that goes its own way needs its own name and logo, so that
nobody mistakes it for Athena's releases. Keep the copyright notices and the
AGPL, as the licence requires, and say which version of Athena it started
from.

To ask about anything here, write to [athena@hojo.dev](mailto:athena@hojo.dev).
